# MA1101 — Introducción al Álgebra

Material de estudio, controles históricos, pautas de corrección y resúmenes teóricos para el curso **MA1101 (Introducción al Álgebra)** de la Escuela de Ingeniería y Ciencias (Plan Común, FCFM Universidad de Chile).

---

## 📂 Contenido

```
Algebra/
├── Controles/   # Enunciados oficiales de controles (2023 - 2026)
├── Pautas/      # Solucionarios y pautas oficiales de corrección
├── Resumenes/   # Apuntes condensados y síntesis por control en Markdown
└── Libros/      # Material complementario y libros de referencia
```

---

## 📑 Unidades y Material

- **Controles**: Controles 2, 3, 4, 5 y recuperativos de períodos Otoño, Primavera y Verano (2023–2026).
- **Pautas**: Pautas detalladas de corrección de cada evaluación correspondiente.
- **Resúmenes**: Síntesis en formato Markdown con teoremas, propiedades y métodos de resolución para repasos rápidos.
- **Libros**: Textos guía complementarios (combinatoria, estructuras algebraicas).
