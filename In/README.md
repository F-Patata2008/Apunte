# Instituto Nacional — Apuntes y Trabajos de Enseñanza Media

Colección de apuntes, guías, ensayos y trabajos elaborados durante la enseñanza media en el **Instituto Nacional José Miguel Carrera** (Santiago de Chile), organizados por asignatura.

## 🛠️ Compilación
Cada documento en LaTeX es independiente. Para compilar cualquier apunte, ingresa a su respectivo directorio y ejecuta:
```bash
pdflatex archivo.tex
# o bien
latexmk -pdf archivo.tex
```
